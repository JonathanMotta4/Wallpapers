# Wallpapers
A personal collection of wallpapers for desktop customization, featuring anime, digital art, landscapes, nature, and more.

## Collection

- **Anime & Manga** — Anime-inspired artwork and favorite characters.
- **Digital Art** — Illustrations, aesthetic backgrounds, and original-looking artwork.
- **Nature & Landscapes** — Flowers, beaches, islands, and scenic views.
- **Wallhaven** — A large collection of high-resolution wallpapers.
- **Live Wallpapers** — Selected video wallpapers in `.mp4` format.

## Live Wallpapers

Video wallpapers are included alongside static images for use with compatible wallpaper applications.

- `extra.mp4`
- `kessoku-band-in-the-train-bocchi-the-rock-moewalls-com.mp4`

## Usage

Clone the repository:

```bash
git clone <repository-url>
cd Wallpapers
```

Choose any wallpaper and set it using your preferred desktop environment or wallpaper manager.

## Notes

- The collection includes `.jpg`, `.jpeg`, `.png`, `.webp`, and `.mp4` files.
- Some wallpapers are available in 4K resolution.
- Images and videos may belong to their respective creators.
